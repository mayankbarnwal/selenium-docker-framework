# Automation Test Framework

## Overview

This project is a Maven-based automation testing framework using Selenium and TestNG. It is designed for scalable UI testing with clean structure and reusable components.

## Tech Stack

* Java
* Maven
* Selenium WebDriver
* TestNG

## Project Structure

* `src/test/java` → Test cases
* `src/main/java` → Utilities and core framework
* `pom.xml` → Dependency management

## Setup Instructions

1. Clone repository
2. Import as Maven project in Eclipse
3. Run:

   ```
   mvn clean test
   ```

## Reports

Test execution reports are generated in:

```
test-output/
```
